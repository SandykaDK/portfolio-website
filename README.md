# 🚀 Personal Portfolio & Showcase

A modern, responsive, and interactive personal portfolio website designed to showcase my experience, education, and technical projects. Built using **React.js**, **Material UI v5**, and **Framer Motion** for sleek UI transitions and personal branding.

## ✨ Key Features

- 🌓 **Light / Dark Mode:** Custom theme palette powered by Material UI `ThemeProvider`.
- 📱 **Fully Responsive:** Smooth layout adjustments across mobile, tablet, and desktop viewports.
- ✨ **Fluid Animations:** Scroll-triggered entry animations and interactive hover effects powered by Framer Motion.
- 🖼️ **Interactive Project Showcase:** Image sliders (carousel) for project screenshots with modal dialogs for deep-dive descriptions.
- ⏳ **Experience & Education Timeline:** Clean visual presentation of professional history and academic achievements.
- 📄 **CV Download & Social Links:** Direct access to resume PDF and social channels (LinkedIn, GitHub, Instagram, Email).
- 🔤 **Custom Typography:** Space Grotesk (Headings) + DM Sans (Body) fonts.

---

## 🛠️ Tech Stack

- **Frontend:** [React.js](https://reactjs.org/)
- **UI Component Library:** [Material UI (MUI v5)](https://mui.com/)
- **Animation:** [Framer Motion](https://www.framer.com/motion/)
- **Carousel / Slider:** [Swiper.js](https://swiperjs.com/)
- **Icons:** `@mui/icons-material`
